ОБНОВЛЕНИЕ ИНТЕРФЕЙСА ДЛЯ ОДИНОЧНОЙ И МУЛЬТИПЛЕЕРНОЙ ИГРЫ

Что изменено:
- Новая общая таблица стилей strategy-ux.css применяется к обеим режимам: одиночная кампания и мультиплеер.
- Главное меню стало горизонтально прокручиваемым и удобнее на телефонах; активный раздел заметнее.
- Подразделы экономики, власти, мира и развития отделены визуально от главных разделов.
- Панель времени и кнопки управления перестраиваются на узких экранах, чтобы не занимать половину экрана.
- Карточки, таблицы, формы и кнопки получили адаптивные размеры; таблицы можно прокручивать по горизонтали.
- Панель быстрого доступа мультиплеера приведена к той же визуальной системе и удобным зонам нажатия.
- Добавлен маршрут /strategy-ux.css в app.py; версии game.js и nations.js обновлены для сброса кэша.

Игровые правила и сетевой протокол не менялись этим UX-патчем. Экономика, армия и политика остаются теми же системами game.js, доступными из сетевой партии через общий интерфейс; мультиплеерные дипломатия, команды войны и синхронизация остаются в nations.js/nations_server.py.

Проверки:
- node --check game.js
- node --check nations.js
- python -m py_compile app.py
- python test_multiplayer_updates.py
