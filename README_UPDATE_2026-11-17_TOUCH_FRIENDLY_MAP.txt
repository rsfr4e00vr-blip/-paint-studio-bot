NOVARIA — УДОБНАЯ КАРТА ДЛЯ ТЕЛЕФОНА

- Целевое количество провинций не меняется: генератор province_grid.js по-прежнему создаёт около 3000 игровых провинций (если исходных больше — не сокращает).
- При первом открытии мировой карты камера автоматически приближает государство, за которое играет пользователь. Это делает провинции визуально крупнее на экране; кнопка сброса возвращает общий обзор мира, масштабирование и перетаскивание остаются доступны.
- Добавлены прозрачные SVG-зоны нажатия шириной 10 CSS-пикселей по границам провинций. Они не меняют геометрию, цвет, владельца, экономику или количество провинций.
- Видимые границы провинций стали чуть контрастнее.
- Выбор провинции по прозрачной зоне открывает то же окно страны, что и обычное нажатие по карте.

Проверки: node --check game.js; node test_province_grid.js; node test_regions.js.
Примечание: визуальный тест на физическом Android-устройстве и тест попадания по каждой из 3000 областей вручную не выполнялись.
