NOVARIA — ОБЪЕДИНЁННОЕ ОБНОВЛЕНИЕ С МУЛЬТИПЛЕЕРОМ

В один проект сведены прежние обновления экономики, ресурсов, арсенала и ИИ, карты и регионов, валюты и военных экономических потерь, дипломатии, национальных проектов, внутренней политики, разведки/контрразведки и удобного управления войной. Существующие сетевые механики (комнаты, таблица, чат, помощь, пакты, санкции, войны, вассалы, передача областей) сохранены.

Что добавлено/подключено к сетевой партии:
- Внутренняя политика и национальные проекты работают в личном сохранении каждой страны участника.
- Разведывательные сети, разведывательные отчёты и контрразведка доступны в мультиплеере.
- Мировые кризисы теперь создаются сервером один раз на комнату и одинаковы для всех участников; ответные меры каждый игрок принимает отдельно.
- Дипломатия игроков расширена: подарки, культурный обмен, саммиты, гуманитарная помощь, образовательный обмен и посольства. Сервер проверяет расходы, ограничения и перезарядки. Посольства оплачиваются по 20 млн за активный месяц, работают до 24 активных месяцев и улучшают отношения.
- Военный штаб мультиплеера получил планы: наступление, баланс, оборона, экономия, давление на экономику и автоподбор. Сервер принимает приказы, синхронизирует их для обеих сторон и применяет игровые бонусы/расходы.
- Действия в локальных системах государства сохраняются в локальном сохранении мультиплеера, а не только после следующего игрового месяца.

Проверки: node --check game.js; node --check nations.js; python -m py_compile app.py nations_server.py test_multiplayer_updates.py; python test_multiplayer_updates.py; node test_ai_nations.js; ZIP integrity. Полный визуальный тест браузера на двух физических устройствах и развёртывание на хостинге не выполнялись.
