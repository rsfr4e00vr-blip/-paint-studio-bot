PAINT STUDIO — ОБНОВЛЕНИЕ ИНТЕРФЕЙСА И СОХРАНЕНИЙ

Интерфейс
- Обновлена панель управления кампанией в духе grand strategy / Hearts of Iron IV: строгая военно-стратегическая палитра, металлические рамки, золотые акценты, компактные кнопки и горизонтальная панель разделов.
- На телефонах кнопки сохранения и обмена файлами переходят в отдельную строку, чтобы их было удобно нажимать.
- Добавлены быстрые действия: сохранить, экспортировать и импортировать кампанию.

Экспорт
- Создаёт JSON-файл с версией формата, датой экспорта и полным состоянием кампании.
- На Android после экспорта проверь папку «Загрузки» / Downloads.

Импорт
- Принимает новый версионированный JSON и старые JSON-сохранения предыдущих версий.
- Проверяет структуру файла перед загрузкой.
- Перед заменой текущей кампании показывает подтверждение.

Установка
1. Распакуй архив.
2. Загрузи все файлы из папки paint-studio-fixed в корень GitHub-репозитория, заменив старые.
3. Сделай Commit changes.
4. На Render выбери Manual Deploy → Deploy latest commit.
5. После запуска открой раздел «Настройки» и проверь экспорт/импорт на копии сохранения.

Проверки
- Все JavaScript-файлы прошли node --check.
- Python-файлы прошли py_compile.
- Проверка синтаксиса не заменяет реальный тест запуска на Render.
