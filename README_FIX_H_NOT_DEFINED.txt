ИСПРАВЛЕНИЕ: «Uncaught ReferenceError: H is not defined»

Причина: в game.js строка H.goalUi=... (цели войны) выполнялась раньше, чем создавался объект window.H (он создавался только ниже по файлу). Из-за этого весь game.js падал при загрузке.
Исправление: window.H=window.H||{}; добавлено в самое начало game.js.
Версия кэша game.js в game.html повышена до v=47 (иначе браузер/Telegram покажет старый файл).

Объединение: архив «state-simulation-unified-update» оказался более старым снимком проекта (без целей войны). Всё его содержимое (systemic_sim.js и т.д.) уже есть в основной игре, поэтому итог = основная игра + исправление.
