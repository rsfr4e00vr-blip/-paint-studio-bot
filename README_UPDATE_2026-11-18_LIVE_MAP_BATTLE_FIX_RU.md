# Novaria — исправление боя и арсенала на реальной карте (18.11.2026)

## Что исправлено

1. Арсенальные и военные сцены больше не создают отдельное всплывающее окно с копией карты. Ракета, дрон, снаряд, самолёт и взрыв рисуются SVG-слоем прямо поверх текущей мировой карты; исходный масштаб и положение карты не меняются.
2. Размер визуальных эффектов зависит от текущего приближения карты: на общем виде они компактнее, при приближении становятся отчётливее. Эффекты не перехватывают касания карты.
3. Очередь атак противника снова запускает визуальные сцены. Раньше `fxPush` был отключён, поэтому удары ИИ оставались только в журнале/расчётах.
4. Вражеская армия теперь может отбить область, которую игрок временно занял во время войны. Ранее проверка требовала, чтобы область уже принадлежала игроку, хотя военная оккупация не меняла постоянного владельца; из-за этого условие никогда не срабатывало.
5. При успешном отбивании область удаляется из списка временно занятых игроком, карта обновляется, снимается маркер его передовой базы, уменьшается прогресс войны.
6. ИИ выбирает точки пополнения ближе к вторгшимся сухопутным войскам, а не только случайно по всей стране, и получает приоритет на контратаку при вторжении.
7. Значки армий, баз и щиты ПВО с плюсом становятся заметными при приближении карты и скрываются/затухают на дальнем общем виде, чтобы не загромождать карту.
