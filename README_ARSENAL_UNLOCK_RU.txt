NOVARIA — ОТКРЫТЫЙ АРСЕНАЛ

Изменён файл game.js.

Что изменено:
- убраны требования к количеству военных заводов для покупки оружия;
- убраны требования к количеству военных заводов для запуска производства оружия;
- убраны значки замков и предупреждения о нехватке военных заводов в карточках арсенала;
- цены, расход складского вооружения, стали и деньги сохранены;
- правила применения оружия во время войны сохранены: стрельба по-прежнему требует активную войну.

Установка:
1. Распакуйте архив.
2. В GitHub замените существующий game.js файлом из архива.
3. Не удаляйте и не заменяйте остальные файлы.
4. Commit changes, затем Render → Manual Deploy → Deploy latest commit.

Мультиплеер:
Серверная закупка арсенала уже не проверяет число военных заводов; отдельные серверные ограничения склада и правила войны сохранены.

Проверки:
- node --check game.js
- node test_military_industry_game.js
- node test_military_industry_ai.js
