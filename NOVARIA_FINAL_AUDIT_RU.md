# NOVARIA — итоговая техническая ревизия (17.11.2026)

## Что находится в архиве

Это исходный проект из предоставленного ZIP, сохранённый как единый проект. В нём есть:
- веб-игра (`game.html`, `game.js`) и сервер FastAPI (`app.py`);
- отдельный WebSocket-сервер комнат стратегии (`nations_server.py`, `nations.js`);
- экономические, ресурсные, валютные и межотраслевые модули;
- ИИ государств и нейросетевой слой;
- дипломатия, войны, военные цели, ПВО и арсенал;
- карта и регионы (`world.json`, `world.js`, `world_data.js`, `regions.js`);
- подсистема региональной инфраструктуры и постепенного восстановления (`novaria_worldsystems.js`);
- исходные тесты и предыдущие заметки об обновлениях.

## Дополнительные изменения в этой сборке
- Расширена инфраструктура с 9 до 12 типов объектов на регион.
- Старые сохранения автоматически получают профиль города и новые объекты без сброса существующих регионов/активов.
- Введены последствия состояния портов, аэропортов и складов для торговли, мобильности и снабжения.
- Тест `test_novaria_worldsystems.js` обновлён: проверяет 12 типов, городскую запись, повреждение, историю и постепенный ремонт.

## Существенные ограничения, которые остаются

Этот архив **не является полной реализацией всех требований из большого задания**. По фактическому коду и предыдущему журналу проекта остаются следующие незакрытые пункты:

1. **Инфраструктура:** в этой доработке расширен набор объектов в каждом регионе до 12 типов: жилой фонд, энергетика, вода, заводы, больницы, дороги/транспорт, мосты, связь, образование, морские порты, аэропорты, склады/логистика. Добавлена совместимая миграция городского профиля (название, население, урбанизация, уровень) для старых сохранений. Состояние портов, аэропортов и складов теперь влияет на торговую эффективность, мобильность и снабжение; добавлены региональные индексы услуг и экономики. При этом полноценная модель нескольких отдельных городов внутри одного региона, производственные цепочки каждого объекта и географическая отрисовка повреждений зданий на карте всё ещё не реализованы.
2. **Мультиплеер:** сервер управляет комнатой, игровым временем, дипломатическими действиями, войнами и передачей территорий. Однако экономика и часть симуляции остаются на клиентской стороне; инфраструктурная подсистема не перенесена в авторитетное серверное состояние и не имеет полной серверной синхронизации.
3. **ИИ:** тесты подтверждают ИИ для 194 государств и набор экономических/военных/дипломатических решений. Это не доказывает полноценную адаптивную автономную симуляцию каждой перечисленной системы на уровне отдельного независимого агента с долговременной памятью и равными с игроком действиями во всех подсистемах.
4. **Политика и мировые институты:** присутствуют политические, кризисные, шпионские, дипломатические и технологические элементы, но полноценная парламентская симуляция, депутаты, международные организации и саммиты в полном требуемом объёме не подтверждены.
5. **Карта разрушений:** повреждение инфраструктуры связано с регионами и игровыми показателями, но не подтверждено полноценное географическое отображение состояния каждого отдельного здания/района на детальной карте.
6. **Android:** проект является веб-приложением. В исходном архиве нет Android Studio Gradle-проекта и APK. В текущем окружении Android SDK/эмулятор не подготовлен, поэтому APK не собран.
7. **Сетевое развёртывание:** добавлено атомарное JSON-сохранение комнат мультиплеера и восстановление кампаний после перезапуска. После восстановления игра ставится на паузу, а игроки переподключаются по прежним токенам. Для Render нужно подключить Persistent Disk и задать `NOVARIA_ROOMS_FILE=/var/data/nations_rooms.json`; без постоянного диска файл может исчезнуть при новом деплое. Для нескольких серверных экземпляров всё ещё требуется общее хранилище/Redis и отдельная проверка.

## Запуск

### Локально / Render
1. Установить Python 3.11+.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Запустить: `uvicorn app:app --host 0.0.0.0 --port 8000`.
4. Открыть `/game`.

Для Telegram-бота дополнительно нужны переменные окружения `BOT_TOKEN`, `WEBAPP_URL` и, для Mini App, `MINI_APP_SHORT_NAME`. Без Telegram-токена сайт может работать без запуска бота.

### Важно перед обновлением существующего Render-проекта
Сделайте резервную копию текущего репозитория и переменных окружения. Замените файлы проектом из архива, отправьте изменения в GitHub и дождитесь успешной сборки Render. Для сохранения комнат на Render подключите Persistent Disk (например, `/var/data`) и добавьте переменную `NOVARIA_ROOMS_FILE=/var/data/nations_rooms.json`. Без диска комнаты сохраняются только в файловой системе текущего экземпляра и могут пропасть при новом деплое.

## Дополнительная доработка мультиплеера (17.11.2026)

- Клиент передаёт серверу сводку инфраструктуры: среднее состояние объектов, состояние критической инфраструктуры, количество объектов и городских профилей.
- Сервер ограничивает значения диапазонами и сохраняет их в профиле игрока; показатели входят в публичную таблицу комнаты и переживают восстановление комнаты из файла.
- Повреждённая инфраструктура теперь уменьшает мультиплеерный доход: до −8% при состоянии инфраструктуры 0%; при состоянии 90% и выше штрафа нет.
- Качество инфраструктуры учитывается в компоненте благосостояния при подсчёте очков.
- Таблица мультиплеера показывает состояние инфраструктуры, а панель экономики — собственный показатель.
- Добавлены проверки диапазонов, влияния на доход, публичной синхронизации и сохранения/восстановления.

Ограничение: это синхронизация сводных показателей инфраструктуры, а не передача серверу полного списка каждого объекта по регионам. Локальное состояние объектов остаётся в сохранении клиента.


## Доработка городов на карте (2026-11-17)

- Для каждой существующей области `S.regions` при миграции создаётся собственный профиль города с названием, населением, урбанизацией и уровнем; существующие области и сохранения не заменяются.
- На мировой карте для областей, имеющих географическую привязку, отображается маркер города. Цвет/значок маркера отражает среднее состояние инфраструктуры; рядом показывается количество повреждённых объектов. При приближении появляется подпись города.
- Нажатие на маркер открывает карточку именно этого города со всеми его объектами инфраструктуры и состоянием каждого объекта. Из карточки можно отправить средства на восстановление конкретного объекта.
- Система использует уже существующие 12 типов инфраструктуры (жилой фонд, энергетика, вода, заводы, больницы, транспорт, мосты, связь, образование, порт, аэропорт, склад). Новые отдельные области не создаются; остальная игровая логика не менялась.
- Проверки: `node --check game.js`, `node --check novaria_worldsystems.js`, `node test_novaria_worldsystems.js`, `node test_novaria_integration.js` — успешно. Полный визуальный браузерный тест в этой среде не проводился.
