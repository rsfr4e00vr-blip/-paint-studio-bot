# Автоплан теперь двигает реальную армию + оптимизация (18.11.2026)

## Что было
Территорию «захватывал» абстрактный счётчик фронта (`occupyTick` в game.js), а отряды на карте стояли в столице.

## Что сделано
1. Автоплан («Подобрать автоматически», «Наступление», «Баланс») включает `w.auto`: сухопутные отряды сами идут к целям войны (сначала выбранные в штабе, потом ближайшие), расходятся по разным областям, раненых (<30%) отводят на базу. Ручной приказ игрока не перебивается, пока отряд идёт.
2. Кнопка «🪖 Автоход армии: вкл/выкл» в штабе.
3. Если на карте есть пехота/танки, области занимают только они (7 сек удержания). Счётчик фронта больше не телепортирует оккупацию.
4. Оптимизация: эффекты рисуются одной записью в DOM (раньше `innerHTML+=` перепарсил слой), DOM не трогается при неизменных данных, 20 к/с на телефоне, 7 к/с на паузе, панель обновляется 4 раза в секунду, расчёт путей автоплана — не более 3 за такт.

## Ограничения
Через море армия не пойдёт (нет сухопутного пути) — игра сообщит об этом.
Тест: `node test_auto_army.js`.
