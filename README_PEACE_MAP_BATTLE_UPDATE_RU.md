# Обновление: владельцы, карта, бои, мир и капитуляция

## 1. Владелец провинции
- При клике на любую провинцию показывается **нынешний владелец** (через единый `regionOwner`).
- Отдельно указана **первоначальная страна**.
- Подписи и легенда используют текущего владельца.

## 2. Масштабирование в окне выбора территорий
- Добавлены pinch-zoom двумя пальцами, перетаскивание и колесо мыши.
- Увеличена зона нажатия для маленьких провинций (прозрачный stroke + круг в центре).

## 3. Боевые действия
- Кнопка **«⚔ Боевые действия»** во вкладке Штаб / Фронты.
- Открывает окно с атаками обеих сторон, журналом и кнопками анимации ударов (пехота, наши/вражеские удары).

## 4. Реалистичная капитуляция ИИ
- Капитуляция больше не срабатывает после пары ударов.
- Учитываются: длительность войны, потери, снабжение, окружение, положение фронта, соотношение сил, агрессивность ИИ.
- Функция `aiPeaceDecision(w)` оценивает готовность к миру/капитуляции.

## 5. Мир только по согласию
- Убрано одностороннее «Заключить мир со всеми».
- Кнопка **«🕊 Предложить мир»**: игрок выбирает условия (статус-кво / с контрибуцией).
- ИИ может: принять, отказать, предложить встречные условия или продолжить войну.
- Мир заключается только после согласия обеих сторон.

Все изменения расширяют существующие механизмы (`regionOwner`, war tick, журнал, карта), без параллельных систем.
