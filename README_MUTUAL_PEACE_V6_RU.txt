NOVARIA v6 — МИР ТОЛЬКО ПО ОБОЮДНОМУ СОГЛАСИЮ

Изменение:
1. Фронт больше не завершает войну автоматически при достижении 0% или 100%.
2. Крайние значения фронта ограничиваются 1% и 99%, война остаётся активной.
3. Даже окружение, истощение и капитуляционная готовность противника не завершают войну автоматически.
4. При готовности противника к переговорам появляется сообщение, но война продолжается.
5. Одностороннее навязывание условий через штаб заблокировано.
6. Война заканчивается через предложение мира игроком, только если противник принимает предложение.
7. Если противник отказывается, война продолжается; можно предложить мир позднее.

Установка:
Замените файлы проекта содержимым этого ZIP (или загрузите весь проект в отдельную ветку GitHub).
Перед заменой сохраните резервную копию текущего проекта.

Проверка:
Выполните node --check game.js. Полный игровой тест в браузере и многопользовательский тест следует провести после загрузки проекта.
