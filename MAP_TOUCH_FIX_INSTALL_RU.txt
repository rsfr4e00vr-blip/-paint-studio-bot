NOVARIA — ИСПРАВЛЕНИЕ МАСШТАБА КАРТЫ И ВЫБОРА ПРОВИНЦИЙ

Что изменено:
1. При открытии карты показывается увеличенный региональный вид: активная страна, если она есть на карте; иначе Европа.
2. Кнопка сброса масштаба возвращает к этому удобному виду, а не к слишком далёкой карте всего мира.
3. Для каждой провинции добавлена дополнительная прозрачная область нажатия в центре. Она не меняет границы и владельца провинции.
4. Границы провинций на карте стали заметнее.
5. Названия государств убраны с карты; название показывается после нажатия на страну.
6. Количество провинций и их геометрия не сокращаются и не объединяются.

Какие файлы изменены:
- game.js
- game.html (обновлён номер версии скрипта, чтобы браузер не использовал старый кэш)

Установка через GitHub на Android:
1. Сделайте резервную копию репозитория.
2. В корне репозитория замените game.js и game.html файлами из архива.
3. Сохраните изменения (Commit changes).
4. В Render откройте сервис и запустите Manual Deploy → Deploy latest commit (если автодеплой выключен).
5. После деплоя полностью закройте Mini App/вкладку и откройте заново. При необходимости очистите кэш сайта в браузере Telegram.
