# Novaria — исправления по замечаниям пользователя (18.11.2026)

## Что изменено

1. **Анимация арсенала:** обычный успешный выстрел теперь действительно запускает `strikeScene` на мировой карте. Ранее `strikeScene` отбрасывал все автоматические вызовы без `manual`, поэтому игрок видел только текст/расчёт последствий, но не сцену удара. Вызов с `manual:1` оставлен совместимым с историей и сетевыми событиями. Урон по военным целям, инфраструктуре и ПВО по-прежнему рассчитывается игровой логикой до показа сцены.
2. **Флот:** стартовые, покупаемые и произведённые корабли создаются только после успешного поиска морской клетки. При загрузке старого сохранения корабль на суше переносится в воду; если рядом не найдено море, некорректная единица не остаётся на суше. Вражеский флот также выбирает морскую клетку.
3. **Производительность карты:** частота тяжёлой перерисовки на мобильных устройствах ограничена примерно 24 кадрами/с; симуляция и сохранение продолжают работать отдельно. Ограничен рост массива визуальных эффектов, чтобы всплески боёв не перегружали SVG.
4. **ПВО игрока:** в меню формирования войск добавлена батарея ПВО. При выборе она переводит карту в режим размещения; следующий тап по суше устанавливает видимый жетон ПВО за 500 млн. Установку можно выбрать как подразделение и отдать ей приказ на перемещение (медленное перемещение батареи). На глобальной карте также добавлены отдельные статические маркеры ПВО для стран мира (1–3 по условной мощности); они визуальные и не подменяют числовой расчёт ПВО. Существующая модель ПВО каждой страны и ИИ-системы сохранена.
5. **Стойкость ИИ:** мирные предложения больше не должны завершать войну после первых нескольких месяцев/небольшого истощения. Условия запроса мира ужесточены; ранняя автоматическая остановка по низкой казне/умеренному истощению заменена более длительным порогом.
6. **Военный долг ИИ:** во время войны предельный долг повышен до 115% ВВП. Мирный лимит остаётся ниже. ИИ может выпускать дополнительные военные займы при дефиците казны, истощении или низком боевом духе; проценты, валютное давление и дефолтные последствия остаются в модели.
