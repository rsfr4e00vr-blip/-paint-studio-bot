# Novaria — техническое обновление 20.11.2026 (пять направлений)

## Реализовано в ветке

### 1. Telegram WebView / производительность
- Военная симуляция переведена на фиксированный шаг: 30 Гц на мобильных устройствах, 45 Гц на остальных; догон ограничен четырьмя шагами за кадр.
- Отрисовка SVG отделена от симуляции и ограничена 8 Гц на мобильных, 12 Гц на остальных; пауза — 2 Гц.
- Скрытые вкладки не выполняют цикл карты; часы и attach пропускают работу при скрытом документе.
- Лимит визуальных эффектов — 90 на мобильном и 150 на остальных устройствах; сохранение выполняется при pagehide.
- Для Telegram добавлены viewport-fit, safe-area, expand/disableVerticalSwipes и обработка viewportChanged; версии скриптов повышены для сброса кэша.

### 2. Дальность арсенала
- Введены дальности по типам оружия: пушка 45 км, гаубица 80 км, танк 55 км, РСЗО 240 км, дрон 500 км, ракета 750 км, бомба 260 км, вертолёт 220 км, крылатая ракета 2500 км, бомбардировщик 3500 км.
- Для целей с доступной геометрией рассчитывается расстояние по координатам. Если точной геометрии провинции нет, используется ограниченная оценка фронтовой зоны: 40 км для отмеченного участка фронта, 260 км для прочих абстрактных регионов.
- Удар без подходящей по дальности цели не наносит урон и записывается в журнал как недолет. В боевом донесении отображается дистанция/дальность.

### 3. Капитуляция и аннексия
- Полная оккупация противника больше не останавливает глобальный игровой таймер.
- Полная оккупация игрока переводит кампанию в terminal defeat state и показывает действия «Новая игра» / «Выйти».
- При аннексии очищаются активная война и связанные записи вассалов, союзов, посольств, разведки и режимов; побеждённая страна исключается из активного ИИ.

### 4. Сохранения и мультиплеер
- Существующее локальное сохранение остаётся первым и независимым от сетевой синхронизации.
- Существующее серверное атомарное сохранение комнат и восстановление с паузой проверены имеющимися тестами.
- Существующая синхронизация военных состояний и прямой войны проверена тестовыми сценариями.

### 5. Местность
- Убрана случайная hash-разметка типа местности: единая классификация по географическим координатам и крупным природным зонам используется и для визуального слоя, и для симуляции.
- Добавлены легенда карты и сведения о типе местности при выборе региона.
- Местность влияет на скорость перемещения (существующие коэффициенты) и на входящий урон наземным частям (защитные коэффициенты).

## Ограничение геоданных
Для абстрактных регионов без собственной геометрии дальность считается от условного участка фронта (40/260 км), а не от точной точки провинции. Полностью точная дальность требует координат каждой провинции выбранной страны. Тип местности — географическая стратегическая аппроксимация по координатам/природным зонам, а не импортированная цифровая модель высот.
