# Novaria — войска на глобальной карте (армия, флот, авиация)

## Что добавлено
Новый модуль `military_map.js` + `military_map.css` (подключены в `game.html`, маршруты добавлены в `app.py`).

**2D-модели прямо на карте мира** (SVG, всегда одного размера на экране при любом зуме):
- Сухопутные: 🪖 пехотная армия (жетон с солдатом), 🛡 танковая армия (жетон с танком).
- Флот: эсминец, фрегат, авианосец, подводная лодка (вид сверху, поворачиваются по курсу).
- Авиация: истребители и бомбардировщики (вид сверху, поворачиваются по курсу).
- Синий цвет — ваши части, красный — противник. Над каждой частью полоска состояния.

**Управление (касанием/мышью)**
1. Откройте вкладку «Карта», нажмите кнопку «🪖 Войска» в левом нижнем углу карты.
2. Нажмите на свою часть на карте (или её значок в шторке) — она выделится.
3. Нажмите любую точку карты — часть пойдёт туда сама в реальном времени (жёлтый пунктир — маршрут).
4. Кнопки: ⛔ Стоп, 🏠 На базу, 💣 Бомбить (для бомбардировщика: затем нажмите цель), ✕ снять выбор.
5. Скорость симуляции: ⏸ / 1× / 2× / 4×.
- Армия ходит только по суше, корабли — только по воде (поиск пути A* по маске карты, обход островов и берегов).
- Самолёты летят напрямую; у них есть радиус (круг вокруг базы), топливо, автоматическое возвращение на базу и дозаправка.

**Бои и захват**
- Реальные бои в реальном времени: армия↔армия, корабль↔корабль, подлодки (видны только вблизи), самолёт↔самолёт (перехват, истребитель сильнее против бомбардировщика), бомбардировщики по земле и кораблям, корабли обстреливают побережье.
- Если ваша армия 7 секунд стоит в области страны, с которой идёт война, и рядом нет вражеской сухопутной части — область захватывается (попадает в `war.occ`, на карте появляется штриховка, растёт прогресс войны, новая авиабаза).
- Бомбардировка вражеской области повышает урон по ней и прогресс войны.
- Противник (ИИ): при каждой войне создаёт армии, флот и авиацию, обороняется, перехватывает, делает налёты и может занять вашу область (штраф к стабильности и одобрению).

**Формирование частей**
- В шторке «➕ Сформировать часть» (за деньги/личный состав) и «→ на карту» для самолётов и кораблей, построенных на ваших заводах/верфях.
- В игре сразу выдаётся стартовый состав (2 армии, танки, эсминцы, авианосец, 2 истребителя, бомбардировщик).
- Состав сохраняется в `S.milmap` вместе с сохранением кампании.

## Доработано в полной сборке 2026-11-18
- Мультиплеер: сервер принимает ограниченный и проверенный снимок координат войск каждого игрока, рассылает его остальным; при повторном входе клиент получает последние позиции. Военный слой теперь также подключается в сетевой партии; удалённые армии отображаются отдельным read-only слоем и не подменяют локальные подразделения.
- Штриховка восстаний: на мировой карте диагональной цветной штриховкой отмечается только область, где действительно началось активное восстание (`war` / `unrecognized`). Цвет различает разные восстания; подсказка показывает название территории, движение и поддержку. Обычные этнические регионы без восстания остаются без штриховки. После подавления или разрешения восстания штриховка исчезает.
- Блокада: для кораблей добавлен отдельный приказ «Блокада»; после выхода в морской район рядом с провинцией противника фиксируется нарастающий показатель блокады в записи войны. Координаты портовых объектов пока не выделены отдельным геослоем, поэтому целью служит ближайшая провинция противника, а не точная точка причала.
- Воздушная поддержка: для авиации добавлен отдельный приказ «Поддержка»; самолёт остаётся в назначенном районе и даёт небольшой бонус ближайшим дружественным сухопутным частям в бою.
- ИИ-страны: в проекте уже были реализованы механики вассалитета, ультиматумов и смены правительства в `ai_nations.js`, `game.js` и `nations_server.py`; они сохранены, существующие сценарии проверены.

## Уточнение отображения восстаний
- Этнический состав и доля меньшинства больше не являются основанием для штриховки.
- На глобальной карте штрихуется только территория активного восстания; обычные регионы не получают такую заливку.
- При изменении статуса восстания слой карты перерисовывается по данным сохранения.

## Что нельзя подтвердить программными тестами
- Физическая проверка двух отдельных Android-устройств и сетевого соединения между ними не выполнялась в этой среде. Её нужно провести после публикации на реальном сервере.
- Штриховка показывает только данные, имеющиеся в сохранении игрока; достоверную этническую карту всего мира нельзя построить без проверенного набора этнических данных по каждой провинции.
