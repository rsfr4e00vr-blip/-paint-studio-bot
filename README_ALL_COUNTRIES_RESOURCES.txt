PAINT STUDIO — РЕСУРСЫ ДЛЯ ВСЕХ СТРАН

Что изменено:
- Ресурсная панель привязана к выбранной стране (S.me / S.name).
- Для стран с региональными данными используются собственные административные регионы из WORLD_SEEDS и WORLD.REGS.
- Для остальных государств используется их национальный профиль ресурсов из WORLD_DATA / WORLD, без подстановки украинских областей или чужих регионов.
- Старые сохранённые deposits автоматически пересоздаются при смене страны, поскольку в deposits хранится код страны.
- Италия теперь использует все 20 итальянских регионов из региональной базы, а не искусственный короткий список.

Важно:
- В проекте есть подробная региональная разбивка для части государств. Для стран, у которых в базе пока нет списка административных регионов, показывается один национальный ресурсный профиль. Названия областей не выдумываются.
- Уровни месторождений являются игровыми балансировочными значениями, а не точными оценками геологических запасов.

Установка:
1. Распаковать архив.
2. Заменить содержимое GitHub-репозитория файлами из папки paint-studio-fixed.
3. Сохранить изменения через Commit changes.
4. На Render выполнить Manual Deploy -> Deploy latest commit.
5. Не удалять существующие переменные окружения Render.
