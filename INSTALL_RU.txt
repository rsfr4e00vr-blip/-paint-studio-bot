Novaria — исправление ограничений арсенала

Заменить в GitHub только game.js этим файлом, затем Commit changes и Render → Manual Deploy → Deploy latest commit.

Изменения:
- Покупка вооружения больше не требует военных заводов или уже имеющегося вооружения на складе.
- Производство вооружения больше не требует военных заводов, складского вооружения и ограниченного числа производственных линий.
- Убраны требования к числу военных заводов для авиаэскадрильи и ракетной шахты.
- Денежная цена покупки/производства и требования к деньгам, стали и другим производственным ресурсам сохранены.
