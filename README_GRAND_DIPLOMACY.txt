NOVARIA — GRAND DIPLOMACY
========================

Что добавлено
-------------

1) Общая дипломатическая модель: grand_diplomacy.js
   - Четыре основания войны: territorial, border, ideology, economic.
   - Хранимые претензии, пограничные инциденты, идеологические и экономические споры.
   - Оценка военной готовности, экономики, долгов, стабильности, союзников и тяжести провокации.
   - Отдельная нейросеть дипломатических решений: переговоры, протест, ультиматум,
     подготовка и война. Правила отдельно проверяют допустимость войны.

2) Одиночная игра: game.js + ai_nations.js
   - Игрок выбирает основание и открывает дипломатический кризис.
   - Обычный кризис проходит протест, требования и ультиматум (3 игровых месяца).
   - Серьёзная провокация может разрешить внезапную войну.
   - ИИ-страны формируют реальные претензии после территориальных уступок,
     могут столкнуться из-за границы, идеологии и торговли.
   - В каждой войне сохраняются причина и основание; они отображаются в хронике.
   - Нейросеть использует отдельную дипломатическую модель, а не случайный бросок.

3) Мультиплеер: nations.js + nations_server.py
   - Игрок выбирает идеологию страны в лобби.
   - Можно предъявить территориальную претензию или зарегистрировать пограничный инцидент.
   - Идеологические кризисы возникают при длительном серьёзном ухудшении отношений.
   - Санкции могут стать экономическим основанием для ответных действий.
   - Обычная война требует основания, ультиматума и ожидания двух месяцев.
   - При тяжёлой провокации (85/100) допускается внезапная война.
   - Сервер повторно проверяет основание и сроки: клиент не может обойти правила.

Установка
---------

1. Сделайте резервную копию GitHub-репозитория.
2. Загрузите все файлы из архива в корень репозитория, заменив старые версии.
3. Проверьте, что grand_diplomacy.js находится рядом с game.js и nations_server.py.
4. Сделайте Commit changes.
5. На Render выполните Manual Deploy -> Deploy latest commit.

Проверки
--------

Успешно выполнены:
- node --check для изменённых JavaScript-файлов;
- python -m py_compile app.py nations_server.py;
- node test_grand_diplomacy.js;
- node test_ai_nations.js;
- node test_economy_diplomacy.js;
- python test_multiplayer_updates.py;
- python test_grand_diplomacy_server.py.

Важное замечание об архитектуре мультиплеера
--------------------------------------------

Дипломатия между реальными игроками, основания войн, ультиматумы и старт войны
проверяются сервером. Нейросетевые государства продолжают работать через имеющийся
клиентский симулятор NationsAI; этот проект пока не переносит всю симуляцию 194
нейросетевых государств на сервер.
