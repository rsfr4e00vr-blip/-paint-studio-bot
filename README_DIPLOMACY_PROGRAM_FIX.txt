ОБНОВЛЕНИЕ ДИПЛОМАТИИ И МУЛЬТИПЛЕЕРА

1. Долгосрочная программа улучшения отношений
- На карточке каждой страны в разделах дипломатии и штаба, а также в окне страны на карте появилась кнопка:
  «Улучшать отношения 4 года · 40 ⭐».
- При запуске один раз списывается 40 очков политической власти.
- Программа длится 48 мирных игровых месяцев; каждые 5 месяцев отношения улучшаются на 5 пунктов.
- Во время войны с этой страной программа ставится на паузу. Повторно запустить вторую программу для той же страны нельзя, пока первая действует.
- В мультиплеере программа для игрока-соперника синхронизируется сервером и также стоит 40 ⭐.

2. Реакция на нападение
- Само нападение ограничивает ухудшение отношений с атакованной страной и государствами, которые осуждают нападение: из-за этого события отношение не опускается ниже -30.
- Санкции не запускают войну автоматически.
- Значение отношений -100 само по себе больше не запускает автоматическую войну в одиночной игре.
- ИИ всё ещё может отдельно принять решение напасть по военным условиям; это не автоматическое объявление войны из-за одного только значения отношений.
- В мультиплеере объявление войны ухудшает двусторонние отношения максимум до -30, не вовлекая третьи страны.

Проверки:
- node --check game.js
- node --check nations.js
- python -m py_compile nations_server.py app.py
- node test_ai_nations.js
- отдельная проверка сервера: -80 -> -30 при объявлении войны; третья страна не втягивается; программа списывает 40 ⭐ и даёт +5 через 5 мирных месяцев.

Примечание: проверка реальной сетевой игры на двух телефонах требует запуска обновлённого сервера и двух подключённых устройств.
