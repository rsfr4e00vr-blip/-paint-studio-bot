ИСПРАВЛЕНИЕ PAINT STUDIO / RENDER

ВАЖНО: на скриншоте Render показан деплой от Nov 11, 2026. Это старая сборка.
Архив нужно загрузить в тот GitHub-репозиторий и ту ветку, из которых Render берёт код.

1. Распакуйте архив. Файлы лежат прямо в корне архива.
2. В GitHub откройте подключённый к Render репозиторий и нужную ветку.
3. Замените файлы проекта файлами из архива и сделайте Commit changes.
4. В Render откройте Events/Deploys и запустите Manual Deploy -> Deploy latest commit.
5. Убедитесь, что новый деплой показывает сегодняшнюю дату и новый commit ID.
6. Если ошибка повторяется, пришлите свежие логи именно нового деплоя.

В app.py определена функция draw_scores_command, есть обратный псевдоним
drawscores_command, а регистрация /drawscores использует draw_scores_command.
Это устраняет NameError при условии, что Render действительно запускает этот файл.

Не удаляйте существующие переменные окружения BOT_TOKEN, WEBAPP_URL и
MINI_APP_SHORT_NAME в настройках Render.
