Файлы: app.py, index.html (Paint Studio), game.html (Симулятор Страны), requirements.txt, render.yaml.
Все лежат в КОРНЕ репозитория (без папок).
Render: Build = pip install -r requirements.txt, Start = python app.py
Переменные: BOT_TOKEN, WEBAPP_URL (https://имя.onrender.com, без слэша в конце)
Адреса: / — Paint, /game — игра, /health — проверка.
