PAINT STUDIO — Telegram Mini App + бот

Что внутри:
- app.py — Telegram-бот и веб-сервер
- static/index.html — холст Paint Studio
- requirements.txt — зависимости
- render.yaml — настройки развёртывания на Render

Функции холста:
кисть, ластик, линия, прямоугольник, круг, цвет фона, палитра, произвольный цвет,
толщина кисти, залитые фигуры, отмена/повтор, очистка, экспорт PNG и локальная галерея.

ВАЖНО:
Галерея хранится локально в браузере/Telegram на конкретном устройстве. Она не синхронизируется между устройствами и может очиститься при очистке данных приложения.

РАЗВЁРТЫВАНИЕ:
1. В Telegram открой @BotFather, отправь /newbot и создай бота.
2. Скопируй токен. Никому его не отправляй и не публикуй.
3. Загрузи папку проекта в новый GitHub-репозиторий.
4. На Render создай Web Service и подключи этот репозиторий.
5. Build Command: pip install -r requirements.txt
6. Start Command: python app.py
7. В Environment Variables добавь:
   BOT_TOKEN = токен из BotFather
   WEBAPP_URL = https://ИМЯ-СЕРВИСА.onrender.com
8. Дождись успешного Deploy. Открой адрес WEBAPP_URL в браузере — должна открыться Paint Studio.
9. В Telegram открой своего бота и отправь /start.

Render Free может выключать сервис после 15 минут без входящих запросов; первое открытие после сна может занять около минуты. Для постоянно доступного бота понадобится тариф без такого выключения.

ЛОКАЛЬНЫЙ ЗАПУСК:
Python 3.11+; установи зависимости: pip install -r requirements.txt
Задай BOT_TOKEN и WEBAPP_URL (для локального запуска нужен публичный HTTPS-адрес), затем python app.py.
